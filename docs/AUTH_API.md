# 课程登录接口

2026-10-10 只读核对运行中的 word-api OpenAPI：`http://127.0.0.1:3000/doc/swagger-api-json`，可视文档为 `/doc/swagger-api`。本应用使用 `@ohos/axios` 固定版本 2.2.15；仅登录与账号资料联网，聊天、通讯录、朋友圈和个人资料仍为本地课程数据。

## 连接与契约

基址集中在 `entry/src/main/ets/services/AuthService.ets` 的 `AUTH_BASE_URL`。默认 `http://127.0.0.1:3000` 对应本机课程服务，模拟器需配置 `hdc rport tcp:3000 tcp:3000`。这是本机开发连接；未实现短信服务或生产认证。

| 接口 | 参数 | 成功的 data |
| --- | --- | --- |
| `GET /word/user/code` | 查询参数 `phone: string` | 验证码字符串 |
| `POST /word/user/login` | JSON `{ phone: string, code: string }` | JWT 字符串 |
| `GET /word/user/info` | 请求头 `token: <原始 JWT>` | `{ nickname: string, avatarUrl: string }` |

响应封装为 `{ code: number, message: string, data?: T }`，业务成功要求 `code === 200`。失败时 data 可以缺失，不能因 HTTP 200 就进入主页。返回类型与必需字段经当前 OpenAPI 核对；业务码及有效期沿用此前本机服务调查：201 未登录、202 未填验证码、203 过期、204 错误、205 未填手机号、209 通用失败；验证码直接回包、有效 10 分钟，生成器可能返回 4–8 位数字。应用始终按字符串传递，保留前导零。

## 应用行为

- 手机号去除首尾空白，校验为 1 开头的 11 位数字；可用 `10000000001` 这类虚构课程号码验收。课程接口不会发送短信，首次成功登录可能创建本机课程用户。
- 取码后开始 60 秒倒计时，并显示“填入课程验证码”按钮。凭据不以明文显示；填入后仍需用户点击登录。修改号码会清除旧验证码。
- Axios 统一设置 10 秒读取超时和 10 秒连接超时。页面离开时取消请求、停止倒计时；页面恢复按截止时间恢复倒计时。页面活跃标记和请求序号阻止迟到响应改变页面。取消不能撤销已经到达服务器的操作。
- 请求中禁用重复提交，可随时选择“进入本地体验”取消等待。连接错误、业务失败、缺少 token 或联机资料格式错误都保持未登录。
- 登录成功后携带本次 token 获取 info；只有两步都成功才进入联机状态。token 仅在函数局部内存中用于 info，不存储到磁盘、AppStorage、日志或默认请求头。
- 设置页显示联机昵称和头像（加载失败用课程头像）；本地个人资料独立保存。设置可退出当前登录或返回登录页；冷启动重新选择登录或本地体验，已保存的课程数据不受影响。

实际通过的设备验证只记录在 [测试报告](TEST_REPORT.md)，本文件的行为说明不代表每种服务端异常都已模拟验证。
