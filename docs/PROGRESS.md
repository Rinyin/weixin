## 环境与已知事实

- 工程：Stage 模型，ArkTS，目标 SDK 6.0.2 (API 22)，兼容 SDK 6.0.0 (API 20)。
- 已有资源：哪吒主题头像、图片及本地 MP4。当前页面原为静态列表，尚无路由、API、数据持久化。
- 原报告“Picker 解决持久化”与技术目的不符，采用实际持久化方案并如实记载。
- 当前会话未提供 computer-use 所需的 `node_repl` 工具；原生窗口操作通道不可用。可用 DevEco 配套 Hvigor 与 HDC 对已启动模拟器编译、安装、输入和截图，记录具体使用方式。
- 本机后端 OpenAPI：`http://127.0.0.1:3000/doc/swagger-api-json`。验证码直接回包，不发送短信；有效 10 分钟，生成器可产生 4–8 位。登录首次会创建本地课程账号；错误依业务 code 判断。
- 已建立 `hdc rport tcp:3000 tcp:3000`，供模拟器通过 localhost 使用本机服务；尚待 F6 在应用中验证。
